# Personal RAG

A self-hosted, local-first Retrieval-Augmented Generation (RAG) system for asking questions about your own PDF documents. No API keys, no cloud costs, no data leaving your machine.

Upload a PDF, it gets chunked and embedded locally, and you can ask natural-language questions about it, answered by a local LLM grounded in the document's actual content.

## Features

- 📄 **PDF ingestion** — upload a PDF, it's automatically extracted, chunked, and indexed
- 🔍 **Semantic search** — retrieves the most relevant chunks for a question using vector similarity
- 🤖 **Local LLM generation** — answers are generated by a local Ollama model, grounded in retrieved context
- 🔒 **Fully local** — embeddings, generation, and storage all run on your machine; no external API calls, no API keys required
- ⚡ **Simple stack** — Go backend, vanilla JS frontend, Postgres for storage

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | Go (`net/http`) |
| RAG library | [gorag](https://github.com/StacklokLabs/gorag) |
| LLM + embeddings | [Ollama](https://ollama.com) (`llama3.2`, `mxbai-embed-large`) |
| Vector store | PostgreSQL + [pgvector](https://github.com/pgvector/pgvector) |
| Frontend | HTML/JS (no framework) |

## Prerequisites

- [Go](https://go.dev/dl/) 1.22+
- [Docker](https://docs.docker.com/get-docker/)
- [Ollama](https://ollama.com/download)

## Setup

1. **Pull the required models:**

   ```bash
   ollama pull llama3.2
   ollama pull mxbai-embed-large
   ```

2. **Start Postgres with pgvector:**

   ```bash
   docker compose up -d
   ```

3. **Install Go dependencies:**

   ```bash
   go mod tidy
   ```

4. **Run the server:**

   ```bash
   go run .
   ```

5. Open **http://localhost:8080** in your browser.

## Usage

1. Upload a PDF from the web UI — it's extracted, split into overlapping chunks, embedded, and stored in Postgres.
2. Type a question about the document and hit Ask.
3. The system embeds your question, retrieves the most relevant chunks, and asks the local LLM to answer using only that context.

## API

| Endpoint | Method | Body | Description |
|---|---|---|---|
| `/api/upload` | POST | `multipart/form-data` (`file`) | Extracts, chunks, embeds, and indexes a PDF |
| `/api/query` | POST | `{"question": "..."}` | Retrieves relevant chunks and returns a generated answer |

## Configuration

Model names and connection strings are currently set as constants in `main.go`:

```go
ollamaHost  = "http://localhost:11434"
embedModel  = "mxbai-embed-large"
genModel    = "llama3.2"
databaseURL = "postgres://user:password@localhost:5432/dbname?sslmode=disable"
```

Update these if you're running Ollama or Postgres on a different host/port, or want to swap models.

## Known Limitations

- Retrieval is fixed to the top 5 nearest chunks (no reranking).
- Responses are non-streaming (full answer returned at once, not token-by-token).
- PDF is currently the only supported input format.
